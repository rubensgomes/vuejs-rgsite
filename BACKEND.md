# Back End

This project was created to drive the development of Rubnens' backend supporting
software.  All the backend code is to run on Node.JS and it is initially expected
to be deployed on Rubens' VM server.

# Technologies

* Node.JS <https://nodejs.org/en/>
* KrakenJS <http://krakenjs.com/>
* Express.JS <https://expressjs.com/>
* Grunt Task Runner <https://gruntjs.com/>
* MongoDB <https://www.mongodb.com/>

# User Stories

1. Validate the UI captcha on the server using Google ReCaptcha server APIs
2. Send email with given message and email address

# Setting Up Project
